## Interpretation

- Ghaziabad was the only house where the rescue layer earned live eligibility in this bounded replay.
- Its prior shadow evidence showed positive rescue with zero Top-5 damage, but the 59 live activations happened on targets where the swap did not change whether the actual result was in Top-5; therefore headline Top-5/MRR metrics stayed unchanged.
- Deshawar, Faridabad, and Gali did not earn live activation, so their canonical v3.0 rankings were preserved.
- This is a valid null result: candidate-level rescue evidence can be stable enough to pass historical survival without necessarily adding realized prospective hits in the subsequent live window.
