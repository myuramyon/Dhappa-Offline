# DHAPPA Information Architecture

## Primary navigation
- Dashboard: command center for latest data, next target, integrity, and four house summaries.
- Predictions: consensus-backed prediction surface.
- 36 Consensus: weighted candidate ranking and evidence.
- Engine Lab: searchable engine registry with a standardized detail pane.
- Daily Data: canonical daily draw viewer, import, edit, and export.
- Advanced: audit, backup, metrics, and runtime context.

## Shared context
The target selector and data status remain in the top header. Sidebar state is collapsible and the active route is always highlighted.

## Progressive disclosure
Primary numbers and status are visible immediately. Historical metric windows, raw scores, engine metadata, and audit context remain in supporting or advanced areas.
